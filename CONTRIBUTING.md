# Contributing to B-Cell Roadmap

Thank you for your interest in contributing to the B-Cell Roadmap project!

## Reporting Issues

If you find a bug or have a suggestion, please open an issue in the repository. Provide as much detail as possible, including steps to reproduce the issue.

## Pull Requests

1. Fork the repository.
2. Create a new branch for your feature or fix.
3. Make your changes.
4. Submit a pull request.

Please ensure your code follows the existing style and conventions.

## Development Environment

We use Conda to manage dependencies. You can set up the environment using the provided `environment.yml` file:

```bash
conda env create -f environment.yml
conda activate b-cell-roadmap
```

## Structure

* `Preprocessing/`: Documentation for preprocessing workflows.
* `scripts/`: Executable scripts for the workflows.
